# Самара — Почтовая сводка

Android-приложение на Java для получения писем из нескольких IMAP-ящиков, анализа отключений, аварий и ремонтных работ в Самаре за выбранную дату и формирования текстовой сводки.

## Сборка APK

В GitHub откройте **Actions → Build Android APK**. После успешной сборки скачайте артефакт **SamaraMailReport-APK**, распакуйте его и установите `app-debug.apk` на Android.

Требуются Android SDK 35, JDK 17, Gradle 8.9. Сборка запускается GitHub Actions автоматически при отправке файлов в `main`.

## Ограничения

Первоначальная версия использует ключевые слова, извлекает текстовые сообщения (без вложений) из INBOX, не объединяет дубликаты происшествий и не гарантирует полноту отчета. Данные сверяйте с письмами. Пароли приложения шифруются локально с помощью Android Keystore, в репозиторий не загружаются.
