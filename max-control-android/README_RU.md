# MAX Контроль поручений — Android

Приложение Android открывает веб-интерфейс сервера MAX Контроль поручений. При первом запуске укажите адрес сервера, например `https://your-domain.example/`. Для локальной проверки можно использовать HTTP-адрес компьютера в той же Wi-Fi сети.

## Сборка APK

GitHub Actions собирает debug APK из этой папки. После успешной сборки откройте Actions и скачайте артефакт `MAX-Control-Porucheniy-APK`. В архиве находится `app-debug.apk`.

## Требования для работы

- Развёрнутый сервер из комплекта MAX_Control_Porucheniy.
- Доступный с телефона адрес сервера.
- Настроенный бот MAX и права доступа к выбранным групповым чатам.

Сам APK является клиентской оболочкой. Он не читает личные чаты MAX напрямую и не заменяет сервер мониторинга.
